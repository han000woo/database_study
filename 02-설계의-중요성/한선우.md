## 핵심 요약
데이터베이스 설계 짱짱 중요함 

시스템에 뼈대를 만든는 중요한 과정이므로 시간을 아무리 들여도 부족하지 않음 

좋은 데이터 베이스를 위해 개념적, 논리적, 물리적 설계를 거치며 이 과정은 정규화를 포함함 

수정 이상 : 하나의 정보를 바꾸기 위해 여러 데이터를 수정, 일부 누락시 데이터 불일치 
삽입 이상 : 불필요한 정보 없이는 원하는 데이터를 저장할 수 없는 모순 발생
삭제 이상 : 특정 정보를 삭제하면 유지되어야 할 다른 정보까지 함께 삭제 
성능 저하 : 속도 저하
유지보수 비용 증가


개념적 모델링: 무엇을 저장할 것인가
논리적 모델링: 어떤 구조와 관계로 저장할 것인가
물리적 모델링: 실제 DB에 어떻게 구현할 것인가

개념적 모델링
- 어떤 애플리케이션 혹은 데이터를 저장할 때 필요하겠다 싶은거를 간략하게 표현하거나 설계한 모델링 

논리적 모델링
- 릴레이션과 같이 개념적 모델링에서 구상한 각 테이블을 어떤 PK를 가지고 어떻게 연관관계를 적용할건지 단순 추상적인 개념을 넘어 좀더 
세밀하게 관계를 표현한 모델링 

물리적 모델링
- 우리가 주로 쓰는 SQL기반 설계
- 각 테이블별 자료형은 뭘 쓸것이며 어느정도에 하드디스크를 차지하게 할 것이냐
